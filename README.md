# Sootv

Справочник соответствий профессий и специальностей СПО/НПО по приказам и классификаторам **1988–2022**.

Проект можно открыть без сервера и без запуска команд.

## Запуск

Откройте `public/index.html` в браузере.

Для переноса на другой компьютер достаточно одной папки `public`: все данные собраны в `public/data.js` и `public/legacy-links.js`, а `Node.js` для просмотра не нужен.

## Источники соответствий

| Документ | Что связывает |
|----------|----------------|
| Приказ Госкомвуза № 623 (1994) | специальности 1994 ↔ 1988 |
| Приказ Минобразования № 2714 (2001) | специальности 2001 ↔ 1994 |
| Приказ Минобразования № 4377 (2003) | ОК 009-2003 ↔ 2001 |
| Приказ МОиН № 740 (2009) | профессии 2009 ↔ 1999 |
| Приказ МОиН № 835 (2009) | специальности 2009 ↔ ОК 009-2003 |
| Приказ МОиН № 632 (2014) | 2013 ↔ 2009 |
| Приказ Минпросвещения № 336 (2022) | 2022 ↔ 2013 |

## Пересборка данных

После изменения docx-файлов:

```bash
python scripts/rebuild_specialty_history.py
```

Скрипт обновляет `public/legacy-links.js` (исторические специальности 623/2714/4377) и пересобирает `data/sootv.db`.

## Деплой

GitHub Pages публикует каталог `public` (см. `.github/workflows/pages.yml`).
